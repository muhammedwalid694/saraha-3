# 01 — Project Initiation

بداية المشروع: `npm init` + تثبيت الـ dependencies + ملف الدخول `index.js` (express + cors + helmet + routers + error handler).

```bash
npm init -y
npm i express mongoose dotenv cors helmet bcrypt jsonwebtoken joi multer nodemailer nanoid uuid google-auth-library cross-env
npm run dev
```
